# Class: ANSIEmitter

## Description
`ANSIEmitter` is an optimized rendering engine that converts a `Screen` buffer into a stream of ANSI escape sequences. It is designed to minimize the amount of data generated by tracking the terminal's current state and only emitting SGR (Select Graphic Rendition) codes when the intended state in the buffer differs from what is currently displayed.

The emitter supports:
- **State-Aware Emission:** Diff-based SGR minimization.
- **Color Quantization:** Mapping RGB colors to ANSI-16, ANSI-256, or Truecolor (24-bit).
- **DOS/ICE Modes:** Emulating legacy DOS-style color behavior and high-intensity backgrounds.
- **Region-Based Rendering:** Emitting only a specific `Box` sub-region of the screen.

| Parameter | Type | Default | Description |
|---|---|---|---|
| `palette` | `Palette` | `None` | If provided, forces all colors to be quantized to this palette. |
| `dos_mode` | `bool` | `False` | Enables DOS-style SGR semantics. |
| `ice_mode` | `bool` | `False` | In DOS mode, uses the blink bit for bright backgrounds (Intense Color Environment). |
| `capabilities` | `TerminalCapabilities` | `None` | Custom terminal capability instance. Defaults to auto-detected environment capabilities. |

## Terminal Capability Detection & Mode Overrides

`ANSIEmitter` manages terminal graphics protocol selection (`"kitty"`, `"sixel"`, `"iterm2"`, `"block"`) and color depth policies:

- `detect_capabilities(env: Optional[Dict[str, str]] = None) -> TerminalCapabilities` – Inspects environment variables (`TERM`, `COLORTERM`, `KITTY_WINDOW_ID`, `TERM_PROGRAM`) to detect supported terminal protocols and color depth.
- `get_graphics_protocol() -> str` – Returns the active graphics protocol (`"kitty"`, `"sixel"`, `"iterm2"`, or `"block"`).
- `get_color_depth() -> str` – Returns active color depth (`"truecolor"`, `"ansi256"`, or `"ansi16"`).
- `force_graphics_protocol(protocol: Optional[str]) -> None` – Forces any graphics protocol (e.g. `emitter.force_graphics_protocol("sixel")`). Pass `None` to restore auto-detected mode.
- `force_color_depth(mode: Optional[str]) -> None` – Forces any color depth mode (e.g. `emitter.force_color_depth("ansi256")`). Pass `None` to restore auto-detected mode.

## Methods

### `emit(screen: Screen, box: Optional[Box] = None, raw: bool = False) -> str`
Renders the specified screen region to an ANSI string.

**Arguments Table:**
| Name | Type | Description |
|---|---|---|
| `screen` | `Screen` | The screen buffer to render. |
| `box` | `Optional[Box]` | The rectangular region to render. Defaults to the entire screen. |
| `raw` | `bool` | If `True`, includes explicit cursor positioning sequences for every row. |

**Returns:** `str` - The generated ANSI escape stream.

**Usage Example:**
```python
from libansiscreen.screen import Screen
from libansiscreen.renderer.ansi_emitter import ANSIEmitter

screen = Screen(width=20)
screen.put_text("Hello")
emitter = ANSIEmitter()
print(emitter.emit(screen))
```

### `_compile_cell(prev: TerminalState, cell: Cell) -> TerminalState`
Internal method that determines the desired `TerminalState` for a cell, considering the current mode (DOS/ICE) and quantization policies.

---

### `_encode_color(color: Color, *, fg: bool) -> AnsiColorState`
Internal method that converts an RGB `Color` into its ANSI-space representation (`AnsiColorState`).

---

### `_build_sgr(prev: TerminalState, desired: TerminalState) -> str`
Internal method that compares the previous and desired states to build a minimal SGR escape sequence.

## Helper Classes (in `libansiscreen.renderer.ansi_emitter`)

### Class: Box
A simple container for rectangular coordinates.
- **Attributes:** `x`, `y`, `width`, `height`.
- **Methods:** `contains(x, y) -> bool`.

### Class: AnsiColorState
Represents how a color is encoded in ANSI space.
- **Attributes:** `kind` ("ansi16", "ansi256", "truecolor", "dos"), `value` (tuple of indices or RGB components).

### Class: TerminalState
Represents the complete graphics state of the terminal at a given point.
- **Attributes:** `fg` (AnsiColorState), `bg` (AnsiColorState), `attrs` (bitmask).
